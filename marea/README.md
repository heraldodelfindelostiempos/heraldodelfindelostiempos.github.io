# MAREA

Creado por nachommmartinez.

Juego de surf de un toque para navegador, preparado para GitHub Pages.

**Jugar:** https://heraldodelfindelostiempos.github.io/marea/

Toca la pantalla (o pulsa la barra espaciadora) para saltar desde la ola. Mantén para hacer un backflip con agarre central de la tabla y suelta para enderezar la tabla antes de aterrizar. La pendiente acelera o frena al surfista. El clima recorre día, atardecer, noche y tormenta. Durante la tormenta crecen las olas y la espuma; la música original adapta sus acordes, melodía, bajos, filtro y textura de lluvia a cada fase. El botón ♫ silencia la música.

Juego y banda sonora originales. Funciona sin bibliotecas externas; abre `index.html` desde un servidor local para probar cambios.
