# MAREA

Juego de surf de un toque para navegador, preparado para GitHub Pages.

**Jugar:** https://heraldodelfindelostiempos.github.io/marea/

Toca la pantalla (o pulsa la barra espaciadora) para saltar desde la ola. Mantén para girar en el aire y suelta para enderezar la tabla antes de aterrizar. La pendiente acelera o frena al surfista. El clima recorre día, atardecer, noche y lluvia. El botón ♫ silencia la música.

Juego y banda sonora originales. Funciona sin bibliotecas externas; abre `index.html` desde un servidor local para probar cambios.
